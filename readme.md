# 👁️ Universal AI Vision HUD

ระบบตรวจจับ แบ่งส่วน (Segmentation) และติดตามวัตถุ พร้อมหน้าจอ HUD สไตล์ไซไฟ
สร้างด้วย **YOLOv8-seg + OpenCV + Streamlit** รองรับการสั่งงานด้วย **ภาษาไทยและอังกฤษ**

## ✨ ความสามารถ

- 🎯 **เลือกวัตถุที่ต้องการตรวจได้** พิมพ์ชื่อเป็นไทยหรืออังกฤษ หรือเลือกจากรายการ
- 🔬 **ปรับความละเอียดการตรวจจับได้** ทั้งขนาดโมเดล, Confidence, IoU, Image Size, TTA และ Hi-res Masks
- 🎨 **HUD เรืองแสง** Mask โปร่งแสงพร้อมเส้นขอบ glow, กรอบมุม, เป้าเล็ง, ป้ายชื่อพร้อมแถบความมั่นใจ
- 🎥 **วิดีโอ** ติดตามวัตถุด้วย ByteTrack (มีหมายเลข ID), เส้นสแกนเคลื่อนที่, แสดง FPS, บันทึกวิดีโอผลลัพธ์ได้
- 📊 **แดชบอร์ดสรุปผล** การ์ดสถิติ, กราฟแท่ง, ตารางรายละเอียดวัตถุ, ดาวน์โหลดภาพ/วิดีโอผลลัพธ์
- 🇹🇭 **ป้ายชื่อบนภาพเป็นภาษาไทยได้** (ต้องมีฟอนต์ไทย ดูหัวข้อฟอนต์ด้านล่าง)

## 📁 โครงสร้างโปรเจกต์

```
universal_vision/
├── app.py                  # จุดเริ่มต้น: หน้าเว็บ Streamlit (Sidebar + แท็บรูป/วิดีโอ)
├── requirements.txt
├── README.md
│
├── core/                   # 🧠 สมองของระบบ (ไม่ยุ่งกับหน้าจอ)
│   ├── engine.py           #   ตรวจจับ YOLO, กรองคลาส, tracking
│   ├── targets.py          #   แปลงข้อความไทย/อังกฤษ → คลาสของโมเดล
│   └── analytics.py        #   Command Center: trails, heatmap, นับ IN/OUT, โซนหวงห้าม, event log
│
├── rendering/              # 🎨 การวาดภาพ
│   └── visualizer.py       #   HUD, mask เรืองแสง, glow, ข้อความไทย
│
├── ui/                     # 🖥️ ส่วนหน้าเว็บ
│   └── components.py       #   CSS ธีมนีออน, การ์ดสถิติ, กราฟ, ตาราง
│
├── config/                 # ⚙️ ค่าตั้งต้น (แก้ง่ายที่สุด)
│   ├── theme.py            #   สี NEON_PALETTE, รายการฟอนต์
│   └── labels.py           #   ชื่อไทย 80 คลาส, กลุ่มคำ (GROUPS), คำพ้อง (ALIASES)
│
└── assets/
    ├── css/
    │   └── style.css       # 🎨 ธีมหน้าเว็บทั้งหมด (สี, แอนิเมชัน, การ์ด)
    └── fonts/              # ฟอนต์ไทย (.ttf)
```

### อยากแก้อะไร ไปที่ไหน

| ต้องการ | แก้ไฟล์ |
|---|---|
| เพิ่มคำพ้อง/กลุ่มคำ เช่น "รถกระบะ" | `config/labels.py` |
| เปลี่ยนสีนีออน / เพิ่มพาธฟอนต์ | `config/theme.py` |
| เปลี่ยนหน้าตากรอบ ป้ายชื่อ เอฟเฟกต์ HUD | `rendering/visualizer.py` |
| เพิ่มฟีเจอร์วิเคราะห์ใหม่ (เช่น แจ้งเตือน LINE) | `core/analytics.py` |
| เปลี่ยนโมเดล / พารามิเตอร์ตรวจจับ | `core/engine.py` |
| ปรับตรรกะการอ่านคำที่พิมพ์ | `core/targets.py` |
| แก้สี/แอนิเมชัน/หน้าตาเว็บ | `assets/css/style.css` |
| แก้โครง HTML ของการ์ด/หัวเรื่อง กราฟ ตาราง | `ui/components.py` |
| เพิ่มปุ่ม/แท็บ/ตัวเลือกบน Sidebar | `app.py` |

## 🚀 การติดตั้งและรัน

ต้องใช้ Python 3.9 ขึ้นไป

```bash
# 1) (แนะนำ) สร้าง virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 2) ติดตั้งไลบรารี
pip install -r requirements.txt

# 3) รันแอป
streamlit run app.py
```

ครั้งแรกที่เลือกโมเดล ระบบจะดาวน์โหลดไฟล์ `yolov8*-seg.pt` ให้อัตโนมัติ (ต้องต่ออินเทอร์เน็ต)

## 🎯 วิธีระบุสิ่งที่ต้องการตรวจ

พิมพ์ในช่อง "พิมพ์ชื่อวัตถุ" บน Sidebar ได้หลายแบบ:

| ตัวอย่างที่พิมพ์ | ผลลัพธ์ |
|---|---|
| `คน, รถ, สุนัข` | คน + รถ (car, bus, truck, motorcycle) + สุนัข |
| `person, car, dog` | person + car + dog |
| `ยานพาหนะ` | จักรยาน, รถ, มอเตอร์ไซค์, เครื่องบิน, รถบัส, รถไฟ, รถบรรทุก, เรือ |
| `สัตว์` / `animal` | นก, แมว, สุนัข, ม้า, แกะ, วัว, ช้าง, หมี, ม้าลาย, ยีราฟ |
| `มือถือ laptop` | cell phone + laptop |
| *(ว่างไว้)* | ตรวจทุกวัตถุ |

- คั่นด้วย `,` `;` เว้นวรรค หรือคำว่า "และ" / "and" ก็ได้
- กลุ่มคำที่รองรับ: ยานพาหนะ, สัตว์, อาหาร, อิเล็กทรอนิกส์, เฟอร์นิเจอร์, เครื่องครัว, กีฬา, กระเป๋า
- รองรับคำพูดทั่วไป เช่น `มอไซค์`, `หมา`, `คอม`, `ทีวี` และพิมพ์ผิดเล็กน้อยในภาษาอังกฤษ
- ถ้าระบบไม่รู้จักคำไหน จะแจ้งเตือนสีเหลืองใน Sidebar
- เพิ่มคำพ้องของตัวเองได้ที่ `ALIASES` และ `GROUPS` ใน `config/labels.py`

## 🔬 คำแนะนำการปรับค่า

| ต้องการ | ปรับอย่างไร |
|---|---|
| จับของเล็กหรือไกลให้ได้มากขึ้น | เพิ่ม **Image Size** เป็น 1280–1600 และลด **Confidence** |
| ลดกรอบซ้อนกัน | ลด **IoU** |
| ลดการตรวจผิด | เพิ่ม **Confidence** |
| ความแม่นยำสูงสุด (รูปภาพ) | โมเดล `l` หรือ `x` + เปิด **TTA** |
| วิดีโอลื่นขึ้น | โมเดล `n` หรือ `s`, ลดความกว้างวิดีโอ, เพิ่มค่า **ข้ามเฟรม** |

## 🇹🇭 ฟอนต์ภาษาไทย

OpenCV วาดภาษาไทยไม่ได้ โปรเจกต์นี้จึงใช้ PIL วาดข้อความ โดยค้นหาฟอนต์ตามลำดับ:

1. โฟลเดอร์ `assets/fonts/` ในโปรเจกต์ (`Sarabun-Regular.ttf`, `NotoSansThai-Regular.ttf` หรือ `font.ttf`)
2. ฟอนต์ระบบของ Windows / macOS / Linux

ถ้าไม่พบฟอนต์ไทย ป้ายบนภาพจะกลับไปเป็นภาษาอังกฤษโดยอัตโนมัติ (ส่วนหน้าเว็บยังเป็นไทยตามปกติ)

- ดาวน์โหลดฟอนต์ฟรีได้จาก [Google Fonts](https://fonts.google.com/) (ค้นหา Sarabun หรือ Noto Sans Thai)
- Linux: `sudo apt install fonts-thai-tlwg`

## ⚠️ ข้อจำกัด

- โมเดลตรวจได้เฉพาะ **80 คลาสของ COCO** ไม่รวมสิ่งของนอกชุดนี้ เช่น ยี่ห้อสินค้า หรือชนิดผลไม้ไทย
- ถ้าต้องการตรวจวัตถุอื่น ให้เทรนโมเดลเพิ่ม หรือเปลี่ยนไปใช้โมเดลแบบ open-vocabulary เช่น YOLO-World
- บนเครื่องที่ไม่มี GPU โมเดลขนาด `l` / `x` และค่า Image Size สูงจะช้า
- วิดีโอผลลัพธ์บันทึกเป็น `mp4v` บางเบราว์เซอร์เล่นตรงไม่ได้ ให้ดาวน์โหลดไปเปิดในเครื่อง

## 🛠️ แก้ปัญหาเบื้องต้น

| อาการ | วิธีแก้ |
|---|---|
| `ModuleNotFoundError: lap` | `pip install lap` (ใช้กับ tracking) |
| ป้ายบนภาพเป็นภาษาอังกฤษ ทั้งที่เลือกไทย | ยังไม่มีฟอนต์ไทย ให้วางไฟล์ `.ttf` ในโฟลเดอร์ `assets/fonts/` |
| ไม่พบวัตถุเลย | ลด Confidence หรือตรวจว่าคำที่พิมพ์ตรงกับคลาสของโมเดล |
| ประมวลผลช้า | ใช้โมเดลเล็กลง, ลด Image Size, ปิด TTA |
| ต้องการหยุดวิดีโอกลางคัน | กดปุ่มใดก็ได้บนหน้าเว็บ (Streamlit จะรีรันและหยุดการประมวลผล) |
